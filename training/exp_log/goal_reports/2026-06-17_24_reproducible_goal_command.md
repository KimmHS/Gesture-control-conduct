# Goal Report 24: Reproducible Goal Command

## Purpose

The final plan required a one-command goal interface, but previous docs still marked it as planned.

This report implements the reproducible command wrapper for the current verified pipeline:

```text
audit eval sessions
-> transition-margin classification score
-> streaming replay
-> replay delay analysis
```

It is intentionally partial and non-monolithic. Expensive train/cache/export stages are not forced during every iteration.

## Implementation

New files:

```text
tools/run_right_conducting_goal.py
scripts/run_right_conducting_goal.sh
tests/test_goal_command_cli.py
```

Supported control flags:

```text
--dry-run
--steps intake,stage,prepare,cache,train,detailed,gate,audit,eval,replay,analyze
--train-roots
--eval-roots
--stage-output-zip
--skip-prepare
--skip-cache
--skip-train
--skip-eval
--skip-export
--models
--folds
--normalizations
--window-frames
```

Current verified steps:

```text
audit
eval
replay
analyze
```

`prepare` is implemented for dataset regeneration. Cache/train/export are exposed as interface flags but not forced by the current default run.

After Report 29, the same runner also supports the new-data setup path:

```text
intake -> stage -> prepare
```

After Report 30, it also supports the MotionBERT training path:

```text
cache -> train
```

After Report 32, it also supports the post-training selection path:

```text
detailed -> gate
```

## Command

```bash
bash scripts/run_right_conducting_goal.sh \
  --steps audit,eval,replay,analyze \
  --eval-session dataset/evaluation_transitions/session_20260616_222455_eval \
  --window-frames 60 \
  --stride-frames 3 \
  --normalizations camera \
  --artifact outputs/right_conducting/selected/feature_baseline_live_v0.json \
  --switch-threshold 0.15 \
  --fast-switch-threshold 0.40 \
  --confirm-updates 2 \
  --output-json outputs/right_conducting/right_conducting_goal_run_222455_60f.json \
  --output-md outputs/right_conducting/right_conducting_goal_run_222455_60f.md
```

Dry-run example:

```bash
bash scripts/run_right_conducting_goal.sh \
  --dry-run \
  --steps audit,eval \
  --eval-session dataset/evaluation_transitions/session_20260616_222455_eval \
  --window-frames 60 \
  --stride-frames 3
```
